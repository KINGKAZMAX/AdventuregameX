Each license permits free redistribution; source code for the GPL titles is
available at the linked upstream repositories.

The in-browser emulator is [WasmBoy](https://github.com/torch2424/wasmBoy)
0.7.1 (GPL-3.0-or-later), vendored at `src/vendor/wasmboy/`.

Cartridge shells in the 3D scene reproduce photos/scans of real released
Pokemon cartridges for personal, non-commercial display (sources: Bulbagarden
Archives, gbhwdb.gekkio.fi (CC BY-SA 4.0), game-boy-database.com,
vgcollect.com — see `tools/pokemon-cartridges.json`). The games that actually
run remain the open-licensed homebrew titles listed above.
