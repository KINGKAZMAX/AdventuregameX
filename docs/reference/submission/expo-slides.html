AdventureX 2026 · 8bit 元境

自由意志 GameX Free Will｜8-bit Memory Odyssey

一座可以被进入的数字记忆博物馆——旋转掌机、插入卡匣、重新点亮一段陪伴。

为什么做

把童年藏进屏幕的那代人，长大了

插入卡匣，按下开机键，在微弱的像素光里度过一整个下午。设备会沉默，按键会褪色， 记忆却还在等一次重新启动。我们想造一座能被重新打开的数字博物馆—— 保存的不是硬件，是人与设备相遇时的温度。

是什么

可进入、可操作、可留下痕迹

  • ① 旋转一台可交互的 3D 掌机，从环形卡匣墙上选卡带、插入
  • ② 浏览器里真实运行 15 款开放许可 Game Boy / GBC homebrew 游戏，可存档/读档
  • ③ 两款内置原创小游戏（Tetris、Space Invaders）收纳在 Archive，同样可玩可存
  • ④ 照料一只虚拟宠物：喂食、换色、留下个人痕迹
  • ⑤ 双语中/英，原创 chiptune 背景音乐实时合成
现场演示 — Live Demo 现在切到浏览器：旋转掌机 → 插入一张卡带 → 真实游玩几秒 → 打开 Save state 面板存档/读档 → 切换到 Tamagotchi 喂一次食。全程真实运行，没有预录视频。

技术栈

Three.js · PixiJS · WebAssembly (WasmBoy) · Vite · TypeScript · Web Audio API · IndexedDB / localStorage

诚实的现状

15 张卡带每一张的标签、游戏、存档都已核对一致（不是占位素材）。 更大的 3D 展馆改版、链上记忆凭证、PICO 空间版本仍在开发中，今天展示的是 已经真实可玩的核心体验。
